# BarberFlow 2.0 — Release Notes

## Posicionamento
A interface foi reorganizada para parecer um produto SaaS comercial, e não apenas um painel administrativo.

## Principais melhorias
- Landing page pública para captar agendamentos.
- Login/cadastro com senha.
- Dashboard administrativo refeito com KPIs e receita dos últimos 7 dias.
- Agenda com prevenção de choque de horários por barbeiro.
- Duração real do serviço considerada no conflito.
- Configuração de intervalo da agenda.
- Configuração de antecedência para cancelamento.
- WhatsApp e Instagram configuráveis.
- Perfil público da barbearia configurável.
- Sidebar responsiva para celular.
- Serviços podem ser desativados sem apagar o histórico.
- Persistência mais robusta e tolerante a dados antigos.
- README com orientação para evolução para SaaS multiempresa.

## Próximo marco comercial
Backend + PostgreSQL + autenticação segura + multi-tenancy + WhatsApp + cobrança recorrente.
